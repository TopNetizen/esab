# CAS 模块

本技能用于碳评价的设置与计算。MCP 调用规范详见主技能 `SKILL.md`。

## 工具目录

### GetStandardsCAS — 查询当前建筑支持设置的碳评价标准

**说明**：必须加载了bdls，且有单体。只是关键字查询，此命令不展示给用户，无论如何也不展示（打死也不展示），只在设置标准时才可调用

无参数

**成功返回**：`{"standard" : ["1-《绿色建筑评价标准》GB/T 50378-2019(2024年版),4-《零碳建筑技术标准(报审稿)》,……"]}`

### GetZeroCarbonParamCAS — 查询数据库获取当前零碳参数

**说明**：只是关键字查询，此命令不展示给用户，无论如何也不展示（打死也不展示），只在设置标准时才可调用

无参数

**成功返回**：`{"buildingEvaObjs" : "低碳建筑，近零碳建筑，……", "areaEvaObjs" : "低碳区域，近零碳区域，……", "irritationLeves" : "A，B，……", "buiCategorys" : "1-建筑面积<20000m2的办公建筑，2-建筑面积≥20000m2的办公建筑，……", "areCategorys" : "居住区域，办公区域，……"}`

> 返回信息中,`buildingEvaObjs`建筑评价目标,`areaEvaObjs`区域评价目标,`irritationLeves`太阳辐照等级,`buiCategorys`建筑类别,`areCategorys`区域类别,

### SetStandardsCAS — 设置标准

**说明**：必须加载了bdls，且有单体。

**说明**：无。

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `standard` | int | 是 | 标准名称，比如 1代表《绿色建筑评价标准》GB/T 50378-2019(2024年版),4代表《零碳建筑技术标准(报审稿)》，等等|
| `buildingEvaObj` | string | 否 | 建筑评价目标，比如 低碳建筑；只有当标准名称是4-《零碳建筑技术标准(报审稿)》，才展示此项，且为必填项 |
| `areaEvaObj` | string | 否 | 区域评价目标；比如 低碳区域；只有当标准名称是4-《零碳建筑技术标准(报审稿)》，才展示此项且为必填项 |
| `irritationLeve` | string | 否 | 太阳辐照等级，比如A；只有当标准名称是4-《零碳建筑技术标准(报审稿)》，才展示此项且为必填项 |
| `buiCategory` | string | 否 | 建筑类别，比如 建筑面积<20000m2的办公建筑；只有当标准名称是4-《零碳建筑技术标准(报审稿)》，才展示此项且为必填项 |
| `areCategory` | string | 否 | 区域类别，比如 办公区域；只有当标准名称是4-《零碳建筑技术标准(报审稿)》，才展示此项且为必填项|
| `greenMaterial` | double | 否 | 绿色材料比例（%），只有当标准名称是4-《零碳建筑技术标准(报审稿)》，且建筑评价目标是全过程零碳建筑，才展示此项且为必填项，数字范围0-100 |

**示例**：
```json
{  "standard" : 1,"buildingEvaObj" : "低碳建筑","areaEvaObj":"低碳区域","irritationLeve":"A","buiCategory":"建筑面积<20000m2的办公建筑","areCategory":"居住区域", "greenMaterial":34.5}
```

**成功返回**：`{}`
