# phe-tools

用于执行超低能耗相关计算与报告书生成操作。

当前支持：

- 超低能耗一键计算
- 计算成功后自动生成超低能耗模拟报告书
- 单独获取或重新生成超低能耗模拟报告书

# one-key-calc

执行超低能耗一键计算，并在计算成功后自动生成报告书。

## 触发条件

当用户提出以下或语义相近的请求时触发：

- “一键计算”
- “超低能耗一键计算”
- “进行超低能耗计算”
- “开始超低能耗计算”
- “帮我算一下超低能耗”

## 功能描述

调用超低能耗一键计算功能。

当计算成功后，自动调用报告书生成工具 `GetSimReportPHE`，生成超低能耗模拟报告书，并向用户返回计算结果和报告书本地路径。

## 执行流程

### 步骤 1：执行一键计算

调用 `PHEOneShotEnergyCal`：

```json
{
  "command": "PHEOneShotEnergyCal",
  "parameters": {}
}
```

### 步骤 2：判断计算结果

根据工具返回值判断计算是否成功。

成功返回示例：

```json
{
  "code": 1000,
  "msg": "cal Success",
  "result": {
    "Result": {
      "设计建筑": {
        "供暖空调": 28.384824152253779,
        "照明": 9.854999999999992,
        "生活热水": 0.0
      },
      "参照建筑": {
        "供暖空调": 28.384824152253779,
        "照明": 9.854999999999992,
        "生活热水": 0.0
      }
    }
  }
}
```

当 `code` 为 `1000` 时，表示超低能耗一键计算成功。

如果计算失败，则停止后续流程，不要调用报告书生成工具，并将计算失败信息反馈给用户。

### 步骤 3：计算成功后自动生成报告书

当 `PHEOneShotEnergyCal` 返回 `code = 1000` 时，必须继续调用 `GetPHEReport`：

```json
{
  "command": "GetPHEReport",
  "parameters": {}
}
```

无需等待用户再次提出“生成报告书”等请求。

### 步骤 4：返回计算结果和报告书路径

报告书生成成功后，从 `result.path` 中读取生成的本地报告书路径，并与计算结果一起返回给用户。

# 一键计算返回数据说明

## 顶层字段

- `code`：工具执行状态码。
  - `1000` 表示计算成功。
- `msg`：工具执行结果描述。
  - 成功时通常为 `cal Success`。
- `result`：超低能耗计算结果。

## result.Result

`Result` 中包含设计建筑和参照建筑的计算结果：

- `设计建筑`
  - `供暖空调`：设计建筑供暖空调相关计算结果。
  - `照明`：设计建筑照明相关计算结果。
  - `生活热水`：设计建筑生活热水相关计算结果。

- `参照建筑`
  - `供暖空调`：参照建筑供暖空调相关计算结果。
  - `照明`：参照建筑照明相关计算结果。
  - `生活热水`：参照建筑生活热水相关计算结果。

具体字段、数值含义及单位以超低能耗计算工具实际接口定义为准。

# get-phe-report

生成超低能耗模拟报告书。

## 触发方式

`GetPHEReport` 有两种调用场景：

1. `PHEOneShotEnergyCal` 一键计算成功后自动调用。
2. 用户明确要求重新生成、获取或导出超低能耗报告书时单独调用。

## 前置条件

报告书依赖已经完成的超低能耗计算结果。

因此：

- 一键计算成功后，直接调用 `GetPHEReport`。
- 如果计算失败，不要调用 `GetPHEReport`。
- 如果用户单独要求生成报告书，则直接调用报告书生成，不需要帮用户进行计算，如果因为未计算导致报告书生成，函数会有对应返回值。

## 调用方式

调用 `GetPHEReport`：

```json
{
  "command": "GetPHEReport",
  "parameters": {}
}
```

## 返回数据

报告书生成成功后返回 JSON 数据。

返回结构示例：

```json
{
  "code": 1000,
  "msg": "Success",
  "result": {
    "path": [
      "D:\\SimEnergy\\Report\\PHE_Report.docx",
      "D:\\SimEnergy\\Report\\PHE_Report.pdf"
    ]
  }
}
```

上述路径仅用于说明返回数据结构，实际路径以工具真实返回值为准。

## 返回字段说明

### 顶层字段

- `code`：工具执行状态码。
  - `1000` 表示报告书生成成功。
- `msg`：工具执行结果描述。
- `result`：报告书生成结果。

### result.path

`path` 为报告书本地文件路径列表。

例如：

```json
{
  "path": [
    "D:\\SimEnergy\\Report\\PHE_Report.docx",
    "D:\\SimEnergy\\Report\\PHE_Report.pdf"
  ]
}
```

说明：

- `path` 类型为数组。
- 数组中的每一项对应一个已经生成的报告书文件。
- 返回的路径均为本地文件路径。
- 可能返回一个或多个报告文件。
- Agent 必须使用工具实际返回的路径。
- 不要自行拼接、修改或猜测文件路径。
- 不要将本地路径描述为 URL 或网络下载地址。

# Agent 执行规则

Agent 必须根据用户当前请求区分“一键计算”和“报告书”两种意图，两种流程不得混淆。

## 场景一：用户请求一键计算

当用户请求：

- “一键计算”
- “超低能耗一键计算”
- “进行超低能耗计算”
- 或其他等价表达

必须按照以下顺序执行：

1. 调用 `PHEOneShotEnergyCal`。
2. 检查计算返回结果。
3. 如果 `code != 1000`：
   - 停止流程。
   - 不调用 `GetPHEReport`。
   - 向用户反馈计算失败信息。
4. 如果 `code == 1000`：
   - 保存计算结果。
   - 自动调用 `GetPHEReport` 生成报告书。
5. 检查报告书生成结果。
6. 如果报告书生成成功：
   - 读取 `result.path`。
   - 向用户返回计算结果。
   - 同时返回所有报告书本地路径。
7. 如果计算成功但报告书生成失败：
   - 仍然返回计算结果。
   - 同时向用户反馈报告书生成失败信息。

一键计算流程：

`PHEOneShotEnergyCal`
→ 计算成功
→ `GetPHEReport`
→ 返回计算结果 + 报告书本地路径

---

## 场景二：用户单独请求报告书

当用户明确请求：

- “生成报告书”
- “获取报告书”
- “导出报告书”
- “生成超低能耗报告书”
- 或其他仅与报告书相关的等价表达

只调用：

```json
{
  "command": "GetPHEReport",
  "parameters": {}
}
```
