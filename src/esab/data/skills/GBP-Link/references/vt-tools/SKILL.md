# VT 模块

本技能用于室内风的设置与计算。MCP 调用规范详见主技能 `SKILL.md`。

## 工具目录

### QuickCalculation — 计算

**说明**：必须加载了bdls，且有单栋建筑。

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `stepCount` | int | 是 | 计算步数 |
| `precision` | double | 是 | 计算精度|

**示例**：
```json
{
 "stepCount": 100, "precision": 0.001
}
```

**成功返回**：`{}`
