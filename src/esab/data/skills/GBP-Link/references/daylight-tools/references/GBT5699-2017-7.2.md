

# 采光达标面积比计算方法 (GB/T 5699-2017 第 7.2 条)

a) 将房间各测量点的采光系数值按降序排列 $C=[C_1,C_2,C_3,\dots,C_n]$，并按顺序相加求前 $j$（$j\leqslant n$）个值的平均值 $C_{\mathrm{ave}}(j)$。

b) 当 $C_{\mathrm{ave}}(n)\geqslant C_{\mathrm{aveb}}$（$C_{\mathrm{aveb}}$ 为标准值），则房间的采光达标面积比为 100%；当 $C_{\mathrm{ave}}(j)\geqslant C_{\mathrm{aveb}}$，且 $C_{\mathrm{ave}}(j+1)<C_{\mathrm{aveb}}$，则 $j$ 即为房间采光系数达标的测点数，达标的面积比按式(5)计算：

$$f=j/n \qquad\cdots\cdots\cdots(5)$$

式中：
$f$——单个房间平均采光系数达标面积比；
$n$——房间内总的测点数。

c) 单个房间的达标面积按式(6)计算：

$$A_j=A_\mathrm{d}\times f \qquad\cdots\cdots\cdots(6)$$

式中：
$A_j$——第 $j$ 个房间的采光达标面积。

d) 建筑的达标面积比按式(7)计算：

$$R_\mathrm{b}=\frac{\sum A_j}{\sum A_\mathrm{d}} \qquad\cdots\cdots\cdots(7)$$

式中：
$R_\mathrm{b}$——建筑的达标面积比。
