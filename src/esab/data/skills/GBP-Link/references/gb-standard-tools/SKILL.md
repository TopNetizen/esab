# 绿建评价标准 MCP 工具

绿建评价标准相关的三个 MCP 工具：查询当前标准、获取可选标准列表、设置标准。

## 适用范围

上述工具**仅适用于绿建相关模块**（能耗模拟、超低能耗、能效测评、采光、室外风、室内风、声环境、热环境、室内热舒适、空气质量等），不支持节能、碳排放、碳评价模块。调用前需确保已切换到正确的模块，否则将提示"未激活模块"。

节能模块请使用对应的 GetCurStandard / GetChoiceStandards / SetStandard 工具。

---

## GbGetUserSelStandard

查询当前模块中用户已选择的绿建评价标准名称。

**请求示例**：

```json
{
  "command": "GbGetUserSelStandard",
  "parameters": {}
}
```

**返回结果**：

```json
{
  "code": 1000,
  "msg": "获取当前选择标准成功",
  "result": {
    "StandardName": "《绿色建筑评价标准》GB/T 50378-2019（2024年版）"
  }
}
```

| 返回字段            | 类型   | 说明                     |
| ------------------- | ------ | ------------------------ |
| code                | int    | 状态码（1000 成功）      |
| msg                 | string | 提示信息，失败时说明原因 |
| result.StandardName | string | 当前选择的标准全名       |

---

## GbGetChoiceStandards

查询当前模块中可用的全部绿建评价标准列表。

**请求示例**：

```json
{
  "command": "GbGetChoiceStandards",
  "parameters": {}
}
```

**返回结果**：

```json
{
    "code": 1000,
    "msg": "获取可选标准成功",
    "result": {
        "StandardNames": [
            "《绿色建筑评价标准》GB/T 50378-2019（2024年版）",
            "《绿色建筑评价标准》GB/T 50378-2019",
            "山东省《绿色建筑评价标准》（DB37/T 5097-2026）",
            "《山东省绿色建筑评价标准》DB37/T 5097-2021",
            "《绿色建筑评价标准》GB/T 50378-2014"
        ]
    }
}
```

| 返回字段             | 类型   | 说明                                |
| -------------------- | ------ | --------------------------------- |
| code                 | int    | 状态码（1000 成功）                 |
| msg                  | string | 提示信息，失败时说明原因            |
| result.StandardNames | array  | 可用标准名称列表（string 类型数组） |

## GbSetStandard

为当前模块设置绿建评价标准。

**请求参数**：

| 参数         | 类型   | 必填 | 说明                                                       |
| ------------ | ------ | ---- | ---------------------------------------------------------- |
| StandardName | string | 是   | 目标标准全名，可通过 GbGetChoiceStandards 获取可用标准列表 |
| Synchronous  | bool   | 否   | 是否将同一标准应用到全部绿建模块，默认为 false             |

**请求示例**：

```json
{
  "command": "GbSetStandard",
  "parameters": {
    "StandardName": "《绿色建筑评价标准》GB/T 50378-2019（2024年版）",
    "Synchronous": false
  }
}
```

**返回结果**：

```json
{
  "code": 1000,
  "msg": "标准设置成功",
  "result": {}
}
```

| 返回字段 | 类型   | 说明                             |
| -------- | ------ | -------------------------------- |
| code     | int    | 状态码（1000 成功）              |
| msg      | string | 提示信息，设置失败时说明可能原因 |

**说明**：

- `StandardName` 必须与标准库中的全名完全一致，建议先通过 GbGetChoiceStandards 获取可用标准列表再从中选取。
- `Synchronous` 参数控制是否将设置同步到所有绿建模块。设为 `true` 时，其他绿建模块也会切换到相同的标准。

---

## 使用流程

1. **查询当前标准** — `GbGetUserSelStandard` 查看当前模块已选择的绿建评价标准
2. **查看可用标准** — `GbGetChoiceStandards` 获取当前模块支持的完整绿建评价标准列表
3. **设置标准** — 从列表中选择目标标准名称，调用 `GbSetStandard` 设置当前模块的绿建评价标准
