# sd 模块

本技能用于室外声环境、构件隔声、背景噪声的计算。MCP 调用规范详见主技能 `SKILL.md`。

## 工具目录

### OneKeyComputeSdIn — 构件隔声一键计算

**说明**：必须加载了bdls，且有单体。

无参数

**成功返回**：`{}`


###  GetAnalysisConclusionSdIn — 查询当前建筑的构件隔声分析结论

**说明**：必须加载了bdls，且有单体。若没有进行一键计算，结论为空。成功返回的结论文本以\n分割。

无参数

**成功返回**：`{"analysisConclusion" : "5.1.2 室内空气污染物浓度限量符合规定：氡不大于150Bq/m3，甲醛不大于0.07mg/m3，氨不大于0.15mg/m3，苯不大于0.06mg/m3，甲苯不大于0.15mg/m3，二甲苯不大于0.20mg/m3，TVOC不大于0.45mg/m3。\n5.1.3 室内空气污染物浓度测量应符合下列规定：\n1  除氡外，污染物浓度测量值均应为室内测量值扣除室外上风向空气中污染物浓度测量值（本底值）后的测量值；\n2  污染物浓度测量值的极限值判定应采用全数值比较法。"}`

**室外声环境模拟分析的常规流程为：**
1. 设置噪声源（用户手动操作）；
2. 设置监测点（用户手动操作）；
3. 一键计算（自动完成计算、统计、判断）；
4. 获取统计分析判断结论；
5. 生成报告书。

## 特别说明
1. 计算前需要确保已创建好噪声源并设置好监测点。如果当前没有，则会返回错误信息。
2. 一键计算会自动弹出计算过程界面，计算完成后自动关闭。
3. **不支持**定时计算或后台静默计算。
4. 回复用户时，**不要**直接展示传给工具的参数和工具返回的错误代码，而要将其转换成中文进行回复。
5. 分析判断结论基于用户当前选中的绿建标准。

## 指令映射表

`command` 参数允许的值及其对应的功能说明如下：

### 一键计算
| Command Value | 功能描述 |
| :--- | :--- |
| `SdOutOneAutoCalc` | 执行一键计算（计算配置、计算、统计、判断全流程），接口说明详见 references/SdOutOneAutoCalc.md |

### 结果分析判断
| Command Value | 功能描述 |
| :--- | :--- |
| `SdOutGetResult` | 获取统计分析判断结论（包含最终结论和详细结论，达标判断、季节性分组结论、评分），接口说明详见 references/SdOutGetResult.md |

### 生成报告书（返回报告书路径）
| Command Value | 功能描述 |
| :--- | :--- |
| `SdOutCreateReport` | 生成室外声环境模拟计算分析报告书，接口说明详见 references/SdOutCreateReport.md |

## 调用示例

### 示例 1：一键计算

用户请求："**帮我执行室外声环境计算。**"

**Agent 构建的参数：**

```json
{
  "command": "SdOutOneAutoCalc",
  "parameters": {}
}
```

### 示例 2：获取分析结论

用户请求："**看看结果怎么样，达标了没有？**"

**Agent 构建的参数：**

```json
{
  "command": "SdOutGetResult",
  "parameters": {}
}
```

### 示例 3：生成报告书

用户请求："**帮我生成一份室外声环境分析报告。**"

**Agent 构建的参数：**

```json
{
  "command": "CFDCreateReport",
  "parameters": {}
}
```
