# 住区热环境设计计算与分析工具集 (TED Tools)

本技能提供住区热环境设计（Thermal Environment Design）的操作能力，包括计算、结论获取、报告书生成与查看等功能。该技能是针对室外区域的，室内热舒适分析请查看 `tcd-tools/SKILL.md`。MCP 调用规范详见主技能 `SKILL.md`。

**住区热环境设计分析的常规流程为：**
1. 前处理：网格生成、专业参数设置（暂不支持，需用户手动操作）；
2. 计算配置、工况设置（暂不支持，需用户手动操作）；
3. **计算**（自动完成全部指标计算）；
4. **查看/获取计算结果与结论**；
5. **生成报告书**。

### 特别说明

1. 计算前需要确保已完成网格生成和专业参数设置。如果当前工程数据不完整，相关工具会返回错误信息。
2. 计算时会弹出计算进度条，计算完成后会自动结束。
3. 本模块支持 **国标 GB/T 50378-2019、GB/T 50378-2023**，以及 **上海、重庆、湖南、京津冀、湖北、山东、河北、海南、四川、浙江** 等多套地方绿建标准。
4. 回复用户时，**不要**直接展示传给工具的参数和工具返回的错误代码，而要将其转换成中文进行回复。
5. 分析判断基于当前工程选用的绿建标准，从 SQLite 数据库读取限值进行达标判定。

## 指令映射表

`command` 参数允许的值及其对应的功能说明如下：

### 计算与结论获取

| Command Value | 功能描述 |
| :--- | :--- |
| `TEDCompute` | 执行一键计算（自动完成规定性设计SD、评价性设计PE、降低热岛强度RHII的全部指标计算，并返回达标结论），接口说明详见 references/TEDCompute.md |
| `TEDGetResult` | 获取当前计算结果与结论（不做重新计算，直接提取已有结论数据），接口说明详见 references/TEDGetResult.md |

### 报告书

| Command Value | 功能描述 |
| :--- | :--- |
| `TEDCreateReport` | 生成住区热环境设计分析报告书，接口说明详见 references/TEDCreateReport.md |
| `TEDGetReportPath` | 获取报告书路径（检查文件是否存在），接口说明详见 references/TEDGetReportPath.md |
| `TEDOpenReport` | 打开现有报告书文件，接口说明详见 references/TEDOpenReport.md |

## 核心概念说明

### 三种设计模式

| 模式 | 说明 | 核心指标 |
|------|------|----------|
| **规定性设计 (SD)** | Standard Design，按标准规定的限值逐项判定 | 平均迎风面积比、通风架空率、场地遮阳覆盖率、渗透与蒸发、屋顶绿化率、叶面积指数 |
| **评价性设计 (PE)** | Performance Evaluation，基于性能模拟的综合评价 | WBGT（湿球黑球温度）、HII（热岛强度） |
| **降低热岛强度措施 (RHII)** | 降低热岛强度的专项措施评估 | 道路、屋顶、场地等各项措施的热岛降低效果 |

## 调用示例

### 示例 1：计算

用户请求："**帮我计算一下室外热环境。**"

**Agent 构建的参数：**

```json
{
  "command": "TEDCompute",
  "parameters": {}
}
```

### 示例 2：获取分析结论

用户请求："**看看热环境结果怎么样，达标了没有？**"

**Agent 构建的参数：**

```json
{
  "command": "TEDGetResult",
  "parameters": {}
}
```
