

# SwitchModule

**说明**：

将软件切换至指定模块界面。切换模块时需要系列和模块名称匹配，获取当前系列名称参考 [get-software-series.md](get-software-series.md)。当前软件支持以下系列及对应模块：

民用系列：
1. 单体建模
2. 区域建模
3. 建筑节能
4. 能耗模拟（旧版）
5. 超低能耗（旧版）
6. 能效测评
7. 高效机房
8. 碳排放
9. 方案碳
10. 碳评价
11. 采光
12. 建筑光伏
13. 可再生能源核算
14. 室外风
15. 室内风
16. 热环境
17. 室内热舒适
18. 声环境
19. 空气质量
20. 幕墙光环境
21. 绿材应用

工业系列：
1. 单体建模
2. 区域建模
3. 工业节能
4. 工业碳排放
5. 工业能耗
6. 工业通风
7. 工业采光
8. 工业声环境
9. 工业绿建设计评价
10. 光伏

电力系列：

2. 区域建模
3. 工业节能
4. 工业能耗
5. 变电站碳排放
6. 输电碳排放
7. 电力声环境

既改系列：

5. 既改室外风

环境仿真：

碳排放计算：

3. 碳排放
4. 碳评价

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `moduleName` | string | 是 | 模块名称 |

**调用示例**：

```json
{"moduleName":"采光"}
```

**注意事项**：

- `moduleName` 必须使用上述支持的完整模块名称。
- 如果用户要求切换至不支持的模块，不得调用 `SwitchModule`，应告知用户该模块当前不受支持。
