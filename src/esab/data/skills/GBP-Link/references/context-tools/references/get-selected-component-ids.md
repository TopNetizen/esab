

# GetSelectedComponentIds

**说明**：根据指定的构件类型，获取当前模型中用户选中的所有该类型构件的唯一标识 ID 列表。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `category` | int | 是 | 构件类型，1=普通墙 2=幕墙 3=门，4=窗 5=柱 6=房间 7=遮阳 |

**调用示例**：

```json
{"category":1}
```

**成功返回**：

```json
{"ids":["122","123","124",...]}
```
