# 上下文工具集（Skill）

## 1. 概述

本 Skill 提供一组工具，用于查询和修改 Galp 软件当前运行上下文，包括但不限于：

- 当前所在模块；
- 当前模型视图信息（建筑、标准层、楼层等）；
- 当前选中的构件 ID 列表。

这些工具用于补充用户未明确提供、但执行任务所必需的实时环境信息。

**严格禁止行为**：

严禁通过以下方式替代实时工具调用，违者视为违反规则：

- 直接引用上一轮、任意历史轮次的上下文工具返回结果
- 基于模型自身记忆保留上下文数据
- 以“用户未切换视图”“状态未变化”为假设跳过工具调用

典型正误示例：

- ✅ 正确做法
  第 1 轮：用户问「当前建筑 ID 是多少」→ 调用 `GetCurrentModelView` → 提取 `idBuild` 回答
  第 2 轮：用户问「当前标准层 ID 是多少」→ **重新调用** `GetCurrentModelView` → 提取 `idStdFlr` 回答

- ❌ 错误做法
  第 2 轮直接沿用第 1 轮返回的 `idStdFlr` 作答，不重新调用工具

## 2. 工具列表

| 工具名称 | 功能说明 | 详细文档 |
|----------|---------|---------|
| `GetSoftwareSeries` | 获取软件所属系列名称 | `references/get-software-series.md` |
| `GetCurrentModule` | 获取软件当前运行模块 | `references/get-current-module.md` |
| `GetCurrentModelView` | 获取当前模型视图信息 | `references/get-current-model-view.md` |
| `GetSelectedComponentIds` | 获取当前选中指定类型构件的 ID 列表 | `references/get-selected-component-ids.md` |
| `SwitchModule` | 将软件切换至指定模块 | `references/switch-module.md` |
| `SwitchBuilding` | 切换至指定建筑 | `references/switch-building.md` |

---

## 3. 必须遵循

1. 工具首次调用前必须阅读对应工具文档，并严格按照文档中的参数定义、格式要求填写 `parameters`。禁止臆测参数含义、遗漏必填参数或传入未定义字段。
2. 处理含实时环境语义的需求时，第一步先校验：本轮是否已调用对应上下文工具。未调用则必须先执行调用，再基于返回结果处理业务逻辑。
3. 涉及实时环境的数据时，必须以本轮最新一次工具返回结果作为唯一依据。
