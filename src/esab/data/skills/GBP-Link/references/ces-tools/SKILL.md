# CES 模块

本技能用于碳排放的设置与计算。MCP 调用规范详见主技能 `SKILL.md`。

## 工具目录

### GetUserSelStandardCES — 获取当前设置的评价标准名称

**说明**获取当前设置的评价标准名称，如果在当前可选择的评价标准列表中没有此标准（先查询GetChoiceStandardsCES，但绝不向用户展示查询内容），通常是模型的设置的省份变了，要调用SetStandardCES，自动改为默认匹配列表中的第一个。

无参数

**成功返回**：`{"StandardNameCES" :"《建筑节能与可再生能源利用通用规范》GB55015-2021" }`



###  GetChoiceStandardsCES — 当前可选择的评价标准列表

**说明**当前可选择的评价标准列表

无参数

**成功返回**：`{"StandardNamesCES" :[《建筑节能与可再生能源利用通用规范》 GB 55015-2021,《民用建筑项目节能评估技术规程》DB]33/T1288-2022] }`


### SetStandardCES — 设置当前设置的评价标准名称

**说明**设置当前设置的评价标准名称，如果在当前可选择的评价标准列表中没有此标准，那设置一定不成功，要给用户提示。

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|StandardName|string|是标准名称

**成功返回**：`{}`



### GetCalSelStandardCES — 获取当前设置的计算依据标准名称

**说明**获取当前设置的计算依据标准名称，如果在当前可选择的计算依据标准列表没有此标准（（先查询GetChoiceStandardsCES，但绝不向用户展示查询内容）），通常是模型的设置的省份变了，要自动设置为默认匹配列表中的第一个。

无参数

**成功返回**：`{"StandardNameCES" :"《建筑节能与可再生能源利用通用规范》GB55015-2021" }`



###  GetChoiceCalStandardsCES — 获取当前可选择的计算依据标准列表

**说明** 获取当前可选择的计算依据标准列表

无参数

**成功返回**：`{"StandardCalNamesCES" :[[《建筑碳排放计算标准》GB/T 51366-2019,《江苏省民用建筑碳排放计算标准》DB32/T 4880-2024] }`


### SetCalStandardCES — 设置当前设置的计算依据标准名称

**说明**设置当前设置的评价标准名称，这个标准只能从可选择的计算依据标准列表中获取，如果在当前可选择的计算依据标准列表中没有此标准，那设置一定不成功，要给用户提示。

**参数**：
| 参数 | 类型 | 必填 | 说明 |
|CalStandardName|string|是| 计算依据标准名称

**成功返回**：`{}`
