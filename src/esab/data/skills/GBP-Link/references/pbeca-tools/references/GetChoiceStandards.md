

# GetChoiceStandards

**工具说明**：获取当前可选标准，会区分公居建。

**调用工具 Json**：
```json
{
    "command": "GetChoiceStandards",
}
```

**参数说明**：

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |

**工具执行完返回 Json**：
```json
{
  "code": 1000,
  "msg":"获取当前可选标准成功",
  "bdlsPH":2,//0是公建，1是居建，2是商住，3是工业
  "公建可选标准":["标准xxx","标准xxx"],
  "居建可选标准":["标准xxx","标准xxx"]
}
```
