# BIM 高级工具集（Skill）

## 1. 概述

BIM 高级工具集用于支持 Galp 建筑模型中的高级建模流程和系统级模型操作，提供面向建筑模型全局处理的工具能力。

# 3. 典型工作流

### 根据图纸生成模型

1. 若用户指令中明确了 DWG 图纸的具体路径，则先新建一栋空建筑作为转模载体，随后执行 `替换 DWG 底图` 工具并传入该路径；
   若未明确路径，则跳过上述操作，默认使用当前已打开的建筑与图纸。
2. 执行 `DWG 智能转模` 工具， 将 DWG 图纸解析为含构件的标准层。
3. 校验标准层：若无有效标准层，即使转模工具返回 `1000` 或 提示 `转模成功`，也立即提示“转模失败”并终止流程，不再执行任何操作，**禁止利用之前的图纸或其他历史图纸进行转模**。
4. 校验通过后，以自动模式执行 `楼层组装` 工具，根据标准层生成实际楼层。
5. 任务完成后，仅汇报生成的楼层信息，禁止额外查询详细的构件信息等。

### 模型修复

当用户的提示词未明确说明需要修复的是 建筑模型 还是 区域模型，仅表达为 “模型修复” 或 “修复模型” 等泛化描述时，应按照以下流程执行：

1. 获取当前模型视图信息，并判断当前视图类型。
2. 若当前视图为非区域模型视图，则依次执行：
   (1) 查询当前建筑所有标准层；
   (2) 调用 `模型修复` 工具；
   (3) 调用 `建筑模型大坐标智能纠正` 工具。
3. 若当前视图为区域模型视图，则调用 `区域模型大坐标智能纠正` 工具。

## 4. 必须遵循

1. 工具首次调用前必须阅读对应工具文档，并严格按照文档中的参数定义、格式要求填写 `parameters`。禁止臆测参数含义、遗漏必填参数或传入未定义字段。
