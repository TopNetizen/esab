

# AutoCorrectBigCoordinate

**说明**：将建筑模型整体移动到坐标原点附近，即所有标准层逐层移动，最后进行楼层组装。用于导入的外部模型坐标偏离原点太远的情况，仅适用于建筑模型。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `idBuild` | string | 是 | 建筑 ID |

**调用示例**：

```json
{"idBuild":"109"}
```

# AutoCorrectBigCoordinateByGIS

**说明**：将区域模型整体移动到坐标原点附近。用于解决区域模型坐标偏离原点太远的问题，仅适用于区域模型。

**参数**：无。
