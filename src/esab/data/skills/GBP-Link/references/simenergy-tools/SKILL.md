# simenergy-tools

用于执行能耗模拟相关计算与报告书生成操作。

当前支持：

- 能耗模拟一键计算
- 一键计算成功后自动生成能耗模拟报告书
- 单独生成或获取能耗模拟报告书

## 使用原则

1. 仅当用户意图与【能耗模拟】相关时使用本 Skill。
2. 用户请求“一键计算”时，先调用 `SimOneShotEnergyCal`。
3. 当 `SimOneShotEnergyCal` 计算成功后，自动调用 `GetSimReport` 生成报告书。
4. 用户无需额外提出“生成报告书”。
5. 如果用户单独请求报告书，则只调用 `GetSimReport`。
6. 用户单独请求报告书时，不要自动调用 `SimOneShotEnergyCal` 进行计算。
7. 如果由于尚未计算等原因导致报告书生成失败，直接返回 `GetSimReport` 的失败信息，不要自行补做计算。

# one-key-calc

执行能耗模拟一键计算，并在计算成功后自动生成报告书。

## 触发条件

当用户提出以下或语义相近的请求时触发：

- “一键计算”
- “能耗模拟一键计算”
- “进行能耗计算”
- “开始能耗模拟计算”
- “帮我算一下能耗”

## 功能描述

调用能耗模拟一键计算功能。

当计算成功后，自动调用 `GetSimReport` 生成能耗模拟报告书，并向用户返回计算结果以及报告书本地路径。

## 执行流程

### 步骤 1：执行一键计算

调用 `SimOneShotEnergyCal`：

```json
{
  "command": "SimOneShotEnergyCal",
  "parameters": {}
}
```

### 步骤 2：判断计算结果

根据工具返回值判断计算是否成功。

成功返回示例：

```json
{
  "code": 1000,
  "msg": "cal Success",
  "result": {
    "Result": {
      "设计建筑": {
        "供暖空调": 28.384824152253779,
        "照明": 9.854999999999992,
        "生活热水": 0.0
      },
      "参照建筑": {
        "供暖空调": 28.384824152253779,
        "照明": 9.854999999999992,
        "生活热水": 0.0
      }
    }
  }
}
```

当 `code` 为 `1000` 时，表示能耗模拟一键计算成功。

如果计算失败：

- 停止后续流程。
- 不调用 `GetSimReport`。
- 向用户反馈计算失败信息。

### 步骤 3：计算成功后自动生成报告书

当 `SimOneShotEnergyCal` 返回 `code = 1000` 时，必须继续调用 `GetSimReport`：

```json
{
  "command": "GetSimReport",
  "parameters": {}
}
```

无需等待用户再次提出“生成报告书”等请求。

### 步骤 4：返回计算结果和报告书路径

报告书生成成功后：

1. 从 `result.path` 中读取生成的报告书本地路径。
2. 向用户返回能耗模拟计算结果。
3. 同时返回所有生成的报告书本地路径。

# 一键计算返回数据说明

## 顶层字段

- `code`：工具执行状态码。
  - `1000` 表示计算成功。
- `msg`：工具执行结果描述。
  - 成功时通常为 `cal Success`。
- `result`：能耗模拟计算结果。

## result.Result

`Result` 中包含设计建筑和参照建筑的能耗模拟结果：

- `设计建筑`
  - `供暖空调`：设计建筑供暖空调相关计算结果。
  - `照明`：设计建筑照明相关计算结果。
  - `生活热水`：设计建筑生活热水相关计算结果。

- `参照建筑`
  - `供暖空调`：参照建筑供暖空调相关计算结果。
  - `照明`：参照建筑照明相关计算结果。
  - `生活热水`：参照建筑生活热水相关计算结果。

具体数值含义及单位以能耗模拟系统实际定义为准。

# get-sim-report

生成或获取能耗模拟报告书。

## 触发方式

`GetSimReport` 有两种调用场景：

1. `SimOneShotEnergyCal` 一键计算成功后自动调用。
2. 用户明确要求生成、获取或导出能耗模拟报告书时单独调用。

## 前置条件

报告书通常依赖已经存在的能耗模拟计算结果。

但是 Agent 不负责主动判断是否需要补做计算。

因此：

- 一键计算成功后，直接调用 `GetSimReport`。
- 一键计算失败时，不调用 `GetSimReport`。
- 如果用户单独请求生成或获取报告书，则直接调用 `GetSimReport`。
- 用户单独请求报告书时，**不要调用 `SimOneShotEnergyCal`**。
- 如果由于没有有效计算结果而导致 `GetSimReport` 失败，直接向用户反馈工具返回的失败信息。
- 即使报告书生成失败，也不要自动调用 `SimOneShotEnergyCal` 进行补算。

## 调用方式

调用 `GetSimReport`：

```json
{
  "command": "GetSimReport",
  "parameters": {}
}
```

## 返回数据

报告书生成成功后返回 JSON 数据。

返回结构示例：

```json
{
  "code": 1000,
  "msg": "Success",
  "result": {
    "path": [
      "D:\\SimEnergy\\Report\\SimEnergy_Report.docx",
      "D:\\SimEnergy\\Report\\SimEnergy_Report.pdf"
    ]
  }
}
```

上述路径仅用于说明返回数据结构，实际路径以工具真实返回值为准。

## 返回字段说明

### 顶层字段

- `code`：工具执行状态码。
  - `1000` 表示报告书生成成功。
- `msg`：工具执行结果描述。
- `result`：报告书生成结果。

### result.path

`path` 为报告书本地文件路径列表。

例如：

```json
{
  "path": [
    "D:\\SimEnergy\\Report\\SimEnergy_Report.docx",
    "D:\\SimEnergy\\Report\\SimEnergy_Report.pdf"
  ]
}
```

说明：

- `path` 类型为数组。
- 数组中的每一项对应一个已经生成的报告书文件。
- 返回的路径均为本地文件路径。
- 可能返回一个或多个报告文件。
- Agent 必须使用工具实际返回的路径。
- 不要自行拼接、修改或猜测文件路径。
- 不要将本地路径描述为 URL 或网络下载地址。

# Agent 执行规则

Agent 必须区分“一键计算”和“单独请求报告书”两种意图。

两种流程不得混淆。

## 场景一：用户请求一键计算

必须按照以下顺序执行：

1. 调用 `SimOneShotEnergyCal`。
2. 检查计算返回结果。
3. 如果 `code != 1000`：
   - 停止流程。
   - 不调用 `GetSimReport`。
   - 向用户反馈计算失败信息。
4. 如果 `code == 1000`：
   - 保存计算结果。
   - 自动调用 `GetSimReport`。
5. 检查报告书生成结果。
6. 如果报告书生成成功：
   - 读取 `result.path`。
   - 返回计算结果。
   - 同时返回所有报告书本地路径。
7. 如果计算成功但报告书生成失败：
   - 仍然返回计算结果。
   - 同时返回报告书生成失败信息。

一键计算流程：

`SimOneShotEnergyCal`
→ 计算成功
→ `GetSimReport`
→ 返回计算结果 + 报告书本地路径

---

## 场景二：用户单独请求报告书

当用户明确请求：

- “生成报告书”
- “生成能耗模拟报告书”
- “获取报告书”
- “导出报告书”
- “给我报告书”
- 或其他仅与报告书相关的等价表达

只调用：

```json
{
  "command": "GetSimReport",
  "parameters": {}
}
```

此场景下：

1. 不要调用 `SimOneShotEnergyCal`。
2. 不要自动帮助用户执行能耗计算。
3. 直接根据 `GetSimReport` 的返回结果进行响应。
4. 如果报告书生成成功：
   - 读取 `result.path`。
   - 返回所有报告书本地路径。
5. 如果报告书生成失败：
   - 直接返回 `GetSimReport` 的失败信息。
   - 不要自动调用 `SimOneShotEnergyCal` 进行补算。
6. 除非用户随后明确要求进行能耗计算，否则不得自行调用计算工具。

报告书流程：

`GetSimReport`
→ 成功：返回报告书本地路径

或：

`GetSimReport`
→ 失败：返回失败信息

报告书流程中不得自动插入 `SimOneShotEnergyCal`。
