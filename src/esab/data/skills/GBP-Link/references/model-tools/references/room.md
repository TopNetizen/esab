

# SetRoom

**说明**：修改房间属性，支持批量操作。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `idRooms` | string[] | 是 | 房间 ID 数组 |
| `type` | int | 否 | 房间类型，1=中庭 2=天井 3=封闭阳台 4=开敞阳台 |

除 `idRooms` 以外，其余均为可选的修改属性。

**调用示例**：

```json
{"idRooms":["110","112"],"type":2}
```

# GetRooms

**说明**：查询指定建筑中所有房间属性。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `idBuild` | string | 是 | 建筑 ID |

**调用示例**：

```json
{"idBuild":"109"}
```

# GetRoom

**说明**：查询单个房间属性。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `idRoom` | string | 是 | 房间 ID |

**调用示例**：

```json
{"idRoom":"109"}
```
