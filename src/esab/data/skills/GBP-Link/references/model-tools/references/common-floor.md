

# GetCommonFloors

**说明**：查询指定建筑中所有的普通层属性。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `idBuild` | string | 是 | 建筑 ID |

**调用示例**：

```json
{"idBuild":"109"}
```

# GetCommonFloor

**说明**：查询单个普通层属性。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `idComFlr` | string | 是 | 普通层 ID |

**调用示例**：

```json
{"idComFlr":"112"}
```
