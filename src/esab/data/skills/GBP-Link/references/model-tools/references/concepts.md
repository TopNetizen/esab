

# 行业知识：相关概念与建模流程

## 相关概念

标准层：

* 是一个逻辑上的重复楼层模板，不占据实际高度坐标。
* 包含：墙体、门窗、楼板、柱、房间分割等所有构件的位置与属性。
* 特点：修改标准层，所有引用它的普通层都会同步变更。
* 标准层有一个基点坐标，组装成普通层的时候，普通层的构件会以这个基点坐标为相对原心进行几何变换，这样能让组装的普通层在垂直方向对齐。
* 命名示例：S01, S02, 标准层1，StdFlr01。
* 标准层定义了一个三维空间域，所有属于该标准层的构件（如：墙、幕墙、门、窗、柱等），其几何占用空间必须完全被该空间域包含，不得发生跨层或越界。

普通层：

* 是建筑中实际存在的楼层，具有唯一楼层编号（如F1, F2, 5F）和绝对或相对标高。
* 每个普通层必须引用一个标准层，并附加标高和高度。
* 普通层的构件几何同标准层里的构件，只在高度和位置有区别，位置的区别是通过标准层的基点定位决定的。
* 普通层的构件的非几何参数可以单独修改，修改不会影响标准层及其他普通层。

## 建模整体流程

1. 创建建筑
2. 创建标准层
3. 编辑标准层（墙、门、窗、柱等构件）
4. 楼层组装
5. 检查建筑详细信息，查看层级结构、构件树等信息
