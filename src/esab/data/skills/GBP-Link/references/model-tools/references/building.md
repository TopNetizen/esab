

# CreateBuilding

**说明**：在当前工程中创建新的建筑模型。除非工程中已存在可用建筑对象，否则执行后续建筑相关操作前必须先调用此工具。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 建筑名称 |
| `pH` | int | 是 | 公居建属性：0=公建，1=居建，2=商住两用，3=工业 |

**调用示例**：

```json
{"name":"1#","pH":1}
```

**成功返回**：

```json
{"idBuild":"109"}
```

## SetBuilding

**说明**：修改指定建筑的属性。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `idBuild` | string | 是 | 指定建筑 ID |
| `name` | string | 否 | 建筑名称 |
| `pH` | int | 否 | 公居建属性 |

除 `idBuild` 以外，其余均为可选的修改属性。

**调用示例**：

```json
{"idBuild":"109","name":"2#","pH":1}
```

## GetBuildings

**说明**：查询当前工程中所有单体建筑的信息。

**参数**：无。

## GetBuilding

**说明**：查询某栋单体建筑的信息。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `idBuild` | string | 是 | 建筑 ID |

**调用示例**：

```json
{"idBuild":"110"}
```
