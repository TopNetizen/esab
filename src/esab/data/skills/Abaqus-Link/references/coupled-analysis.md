

# Abaqus 温度—位移耦合分析

先明确是单向顺序耦合还是热—力双向完全耦合，不能只因用户说“热应力”就选择完全耦合。

## 路径选择

| 物理关系 | 路径 |
|---|---|
| 温度影响变形/应力，力学响应不反馈温度 | 热分析 → 温度场映射 → 结构分析 |
| 摩擦热、塑性耗散或变形显著改变传热 | `CoupledTempDisplacementStep` |

顺序耦合是两个可独立验证的分析。必须记录热 ODB、Step、Frame、源区域、目标区域、网格
是否一致以及插值/映射方式。不要只记录一个文件路径就宣称温度已正确导入。

## 材料和参考温度

完全耦合或热应力通常需要：

- 力学本构，例如弹性参数。
- `Material.Conductivity`。
- `Material.Expansion`，并明确 `zero` 或项目参考温度。
- 瞬态还需要 `Material.Density` 和 `Material.SpecificHeat`。

初始温度、热膨胀零应变温度和导入温度的基准必须一致。缺失参考温度会使看似正确的温差
产生错误热应变。

## 完全耦合

版本化 API 主入口为：

- `Model.CoupledTempDisplacementStep(name, previous, response=..., ...)`
- `Material.Expansion(type=..., zero=..., table=...)`

稳态/瞬态、`timePeriod`、`deltmx`、`nlgeom` 和增量参数必须由物理过程决定。完全耦合使用
带温度自由度的耦合单元，例如 C3D8T/C3D8RT/C3D10MT；不能使用纯热 DC* 或纯结构
C3D8R 替代。

## 顺序耦合

1. 热模型使用 `HeatTransferStep` 和热单元求解。
2. 确认热 ODB 的温度字段、Step、Frame 和时间点。
3. 在结构模型中创建来自结果文件的温度预定义场；写代码前查询当前版本的温度场 API。
4. 相同网格映射与不同网格插值要分别验证节点/区域覆盖率。
5. 结构模型使用结构单元、力学 BC 和结构分析步。

不要在同一个 Part 上简单把 DC* 单元名称改成 C3D* 就假定节点顺序、集合和映射已经正确。

## BC、输出和验证

- 热侧需要温度、热流、对流或辐射条件。
- 力学侧必须控制刚体运动；没有机械外载不代表不需要力学约束。
- 常用输出：`NT/NT11`、`U`、`S`，按需要增加热流和应变变量。
- 完全耦合模型必须同时确认温度和位移字段存在。

结果验证包括热平衡、力/力矩平衡、参考温度、热应变数量级、温度映射覆盖率和网格收敛。
固定端或材料界面的应力峰值需要奇异性判断，不能直接把全局最大 Mises 用作验收值。
