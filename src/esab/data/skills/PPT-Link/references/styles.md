

# 设计系统

24 套设计系统，每套一篇 design.md，路径为 `references/design_system/类别/名称/design.md`。

## 用法

- 用户点名了风格，或描述与某套相符（如“杂志风”“深色科技感”“学术答辩”）时，读该篇全文再设计；拿不准选哪套时，挑两三套各用一句话说明，请用户选。
- 每篇分两部分：PART A 是该类别的通用要求，PART B 是这套风格的签名（配色、版式、字体、组件、禁止项、内容密度），两者冲突时以 PART B 为准。
- 一篇演示文稿只用一套，不混入别的风格的配色、字体和组件。
- 照片需求为“多”的风格，页面主要靠照片撑起；用户没有足够的照片时不要选。
- 文中的字体、磅值都按本技能给出（Windows 自带字体，960 × 540 磅的页面），照用；只给倍数的字号，先定正文字号再乘出各级（create.md）。
