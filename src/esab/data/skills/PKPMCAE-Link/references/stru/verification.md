## 第 0 层：先排除"静默零结果"（★ 跑完必做 = **存在性核对**，允许且必须自行执行）

> 本层是 §4b.4 允许的唯一自查：**只判断"结果有没有算出来"**（`cells>0`、步名非 `step-1`、
> 位移/反力不全 0），**不做**ΣR 与总荷载的定量比对、不做体积与理论值比对、不做任何公式推导。
> 下面的体积求和代码只用于**判断几何是否闭合**（0 或半个 → 交付缺陷），不得拿它与理论体积的差值
> 去评判"结果准不准"。发现异常 → 写进交付包「未决问题」并咨询用户，不自行改模型/网格。

`run_script` 返回 `success:true`、`task-log` 写"任务执行成功!"**只代表脚本没抛异常**。
两种典型静默失败都伴随"成功"：

| 症状 | 根因 | 自查 |
|---|---|---|
| 位移/反力/应力**全为 0** | 未指派分析任务 → 算的是软件自动生成的默认分析「分析-1」（只含空步 `step-1`） | 读 `<项目>/genfea-compute*/61_LoadStep.inp`：`*loadStep` 的步名应是自建 `Step_*`、`nCase>=1`；若是 `1 1 0 0 0 step-1` 即中招 → 补 `Job`+`JobManager`（#51） |
| 网格 `cells` 数为 **0**（或只有线/壳、没有体单元） | 几何没闭合（典型：两个 `Crown` 球冠面共用同一条整圆线；`Solid.outer` 面集不封闭） | 读 `pcaestru-mesh/fe_modelSource.json` 的 `len(cells)`；实体模型再做体积求和（#52/#53） |

### ★ 单元类型分布的固定统计方法（2026-10-14/15 实测）

**两种数据源，按需选用：**

**① 读 `pcaestru-mesh/fe_modelSource.json` 的 `cells`（推荐，最省事）**——
按**单元节点数**分类计数：`8=六面体 / 6=棱柱 / 5=金字塔 / 4=四面体`。
这是"分割 / 网格策略是否奏效"的**客观量**，建议写进交付包
（实测用此法量化了六面体占比 `25.5% → 76.3%`）。

**② 读 `genfea-compute-*/12_Elem.inp`（需要与求解器实际输入对齐时）**——
⚠️ **该文件是多段复合格式，禁止整表按固定列索引解析**：

- 行结构为 `单元号 + 类型码 + 截面号 + 节点数 + 节点号…`，**列数随单元类型变化**
  （八节点六面体 **9 列起**、2 节点 Link **仅 3 列**），文件内还夹有其他段；
- 曾按"第 2 列当类型码"计数，结果把**节点号也当成了类型码**，得到上千个假的"单元类型"，
  并一次性打印出上万字符的 `Counter` 明细——**既是错误结论，也是明显的 token 事故**。

**正确做法**：先定位 `*elem` 段，再**按空行切块**（★ 每个单元是**一块多行记录**，不是一行），
从块内固定行位取字段：

```python
from collections import Counter
L = open(os.path.join(CP, "12_Elem.inp"), encoding="utf-8", errors="ignore").read().split("\n")
i0 = next(i for i, l in enumerate(L) if l.strip().startswith("*elem"))   # 段头形如 "*elem 3968"
blocks, cur = [], []
for l in L[i0+1:]:
    if l.strip() == "":
        if cur: blocks.append(cur); cur = []
    else: cur.append(l)
if cur: blocks.append(cur)

types, nnds = Counter(), Counter()
for b in blocks:
    f0 = b[0].split()          # 第 1 行：单元号 + 类型码 + 截面/材料号
    f2 = b[2].split()          # 第 3 行：节点数 + 节点号列表
    types[int(f0[1])] += 1
    nnds[int(f2[0])]  += 1
print("单元数", len(blocks), "| 节点数分布", dict(nnds))   # ★ 只打印汇总，不打印明细字典
```

**2026-10-15 实机复核的确切格式**（RC 柱轴压模型，`nElem=3968`）：`*elem` 段内**每个单元占 8 行**
（块间以空行分隔，实测 3968 块 × 8 行）：

```text
129 28 6                                        ← 行1：单元号 + 类型码 + 截面/材料号
1 1                                             ← 行2：标志位
8 1 145 437 172 201 486 2187 1725               ← 行3：★ 节点数 + 节点号列表
0 / 0 / 0 / 1 0 / 0 0 0                         ← 行4~8：其余标志位
```

实测统计：类型码 `{23: 128, 28: 3840}`；每单元节点数 `{2: 128, 8: 3840}`；
合计 3968 = 日志 `nElem` ✓，且 `3840 = 8×8×60` ⇒ **全为八节点六面体、0 个四面体** ✓。

**交叉验证**：块数之和应等于日志的 `nElem`；实体组数量应等于「各方向分段数之积」。

> ⚠️ ★ **类型码不可用于判型（2026-10-15 本机复核新发现）**：
> 实测两个模型的类型码分布分别为 RC 柱 `{23: 128, 28: 3840}`（23 = Link、28 = 实体），
> 而钢节点分割模型 **`{28: 26952}`——六面体、棱柱、四面体共用同一个类型码 28**
> （其每单元节点数分布为 `{8: 20560, 6: 738, 4: 5654}` → 六面体 **76.28%** / 棱柱 2.74% / 四面体 20.98%）。
> ⇒ **类型码无法区分实体单元的子类型**，判型一律用「**行3 首列 = 每单元节点数**」
> （8 → 六面体、6 → 棱柱、5 → 金字塔、4 → 四面体、2 → Link/杆）；
> 且类型码跨版本稳定性**未验证**，⛔ 不建议硬编码。
> ⛔ 统计脚本**只打印汇总**——大模型的 `Counter` 明细可达上万字符。
> ⚠️ 若只需要单元类型分布而**不想解析 inp**，更省事的路子是读
> `pcaestru-mesh/fe_modelSource.json` 的 `cells`（见上「两种数据源」①）。

### ★ 孤立节点统计（2026-10-15 实测；一切"按坐标筛节点"的检查前先做）

**成因**：圆弧 / 整圆构造的**圆心点与 `kp` 方向点**会出现在有限元网格节点表里，
但被 **0 个单元引用**（实测某节点模型共 **74 个**：18 孔×3 + 6 螺栓×3 + 2 个耦合悬空参考点）。

**影响**：① **不致求解失败**（专门小模型与正式整模型均正常结束、无 `zero pivot`、
模型检查无 error、荷载步全收敛）；② 会**污染节点统计**；③ 会**污染按坐标/半径的筛选**
（实测"孔内是否有母材节点"检查中，12 个初判"误判节点"**全部是孤立圆心点**，真正的孔内母材节点为 0）；
④ 视图里可能显示为游离点。

**统计方法**（在 Agent 本地 `python_executor` 做，⛔ 不写进 PyPCAE 脚本）：

```python
# 先按上节方法把 *elem 段切成 blocks（每单元一块、块间空行分隔），再统计每个节点被引用的次数
ref = Counter()
for b in blocks:
    f2 = b[2].split()                     # 块内第 3 行 = 节点数 + 节点号列表
    n  = int(f2[0])
    for nid in f2[1:1+n]:
        ref[int(nid)] += 1
all_nids = {n["id"] for n in mesh_json["nodes"]}     # mesh_json = fe_modelSource.json
isolated = sorted(all_nids - set(ref))               # ← 孤立节点（被 0 个单元引用）
print("节点总数", len(all_nids), "| 被引用", len(ref), "| 孤立", len(isolated))   # ★ 只打印汇总
```

⇒ **一切"按坐标筛节点"的检查（湿面、受压面、约束圈、孔内母材…），都应先剔除孤立节点再判断。**

`iStep, nSubstep, nCase, sTime, keyInherit, nameStr`，次行为 `numLoad, coefLoad, subType`：

```text
*loadStep 2
1 10 1 1 0 Step_1_load      ← keyInherit=0（加载：自身全量）
1  1 0
2 10 1 1 1 Step_2_unload    ← keyInherit=1（继承上一步）
```

## 第 1 层：模型层核对（生成脚本后立即自检）

| 项 | 判据 |
|---|---|
| 构件计数 | 与顶部常量推导一致：开间 N → 柱位 (N+1)²；层数 N → 节点层 N+1；柱 = 柱位数×层数；梁 = 两向跨数之和×层数；板 = 开间数²×层数 |
| 节点唯一性 | 连接点共享同一 `Node`（无同坐标重复点）；节点总数 = 推导值 |
| 截面挂载 | 每个构件 `sid ≠ -1`；线构件用 `SectionType.Line`、面构件 `Surface`、体构件 `Solid` |
| 几何拓扑 | `Surf.outer`/`inners` 为线构件 id；`Solid.outer` 为面构件 id；圆弧 `Line` 有 `center`+`kp` |
| 单位量级 | 构件尺寸、截面尺寸、网格尺寸同一单位制（SI 为 m）；规范查得的 mm 值已 ÷1000 |
| 网格参数量级 | `basicSize` ≈ 构件特征尺寸的 1/4~1/10；`UserMeshParameter.txt` 的 `*meshSize` 行与脚本一致 |
| 落盘计数（★ 客观判据） | 读 `<项目>/pypcae/pypcae.stru`（`toViewer()` 写）逐项比对推导值：`nodes`、`components.{lines,surfs,solids,felements,plates,walls}`、`sections`、`materials`、`elsets`、`boundary.fixeds`、`setting.iTypeSI`；注意 **`BeamColumn` 落在 `components.felements`**，不是 `lines` |
| 几何体积（实体模型） | 网格后按四面体体积求和 ≈ 理论体积：整球 4/3πR³（R=1 m 实测 4.0851 m³，−2.48%）、半圆柱+半圆锥实测 2.0520 m³（理论 2.0944，−2.0%）。**差一倍 = 几何其实只有半个**（圆弧线起终点取了直径两端而非同一点，#58） |

## 第 2 层：网格收敛性（用户要求时做；默认收口不自动执行）

> ⚠️ **触发门禁**：网格无关性/收敛性研究属"分析与优化"动作——**默认收口流程不自动执行**，
> 也不许"顺手多算一版对比"。仅在用户明确要求（"做网格无关性 / 收敛一下 / 加密重算"）后进行；
> 执行前先复述将改动的网格规格项（尺寸套数、加密部位、预估单元规模与耗时）并更新规格核对表，
> 用户确认后再跑（见 `execution_contract.md` §5 禁止事项、§9 后续门禁）。本节给出的是判据与方法。

```text
同一模型取 2~3 套网格尺寸（如 basicSize = h, h/2, h/4）分别划网格并计算
→ 跟踪关键量（最大位移 / 最大应力 / 一阶频率）
→ |细 − 中| / 细 < 5%  ⇒ 工程收敛，可交付
→ 不收敛              ⇒ 继续加密，或检查几何（碎面/短线）与单元类型
→ 结果振荡            ⇒ 查应力奇异（点约束/尖角）与网格质量
```

- 网格规模参考：`basicSize` 减半，单元数通常增至 2~4 倍（实体可到 8 倍）——**大模型先与用户确认再提交**；
- 壳/板优先四边形主导（`toQuad="true"`）；实体规则几何用 `sweepAndTMesh`（六面体主导），
  复杂几何用 `tMeshOnly`（四面体主导）；
- 应力集中区（孔口、支座）用 `MeshSetting` 局部加密（`ids` 是**构件号**），不要整体加密。

## 第 3 层：结果层基准（混合路线；⛔ 仅用户明确要求核对时使用）

> 下列公式均为教科书基准。取用时必须声明：**"公式与本软件的单元定义/符号约定/平均算法/网格离散方式
> 可能不一致，偏差不等于错误，是否可信请您判断"**；只报差值，不判定对错、不下工程结论。

### 基准 1：简支梁均布荷载（最常用）

```text
跨中挠度 δ = 5·q·L⁴ / (384·E·I)      跨中弯矩 M = q·L²/8  →  σ = M·(h/2)/I
```

> 算例（SI）：L=6 m，b×h=0.3×0.6 m，q_LL=20 kN/m，Q345B（E=2.06e11 Pa）
> → I=0.0054 m⁴、W=0.018 m³；δ_LL=0.303 mm；自重 q_DL=13.86 kN/m → δ_DL=0.210 mm；
> 合计 ≈0.514 mm；M_max≈152.4 kN·m、σ≈8.5 MPa；反力合计 ≈203 kN。
> 见 `../examples/mixed/stru_to_fem_mixed.py`。
>
> **实测对照（2026-10-12，pypcae 2.1.0，13 节点 / 12 梁单元 / 3 荷载步）**：
>
> | 步 | δ 理论 | δ 实测 | 偏差 | ΣRz 理论 | ΣRz 实测 |
> |---|---|---|---|---|---|
> | Step_DL | 0.2103 mm | 0.2155 mm | +2.5% | 83169.2 N | 83169.2 N（1.0000） |
> | Step_LL | 0.3034 mm | 0.3110 mm | +2.5% | 120000.0 N | 120000.0 N（1.0000） |
> | Step_ALL | 0.5137 mm | 0.5265 mm | +2.5% | 203169.2 N | 203170.0 N（1.0000） |
>
> 节点 Mises 最大 8.465 MPa（理论 σ=M/W=8.47 MPa，−0.06%）。
> ★ **挠度 +2.5% 不是误差**：程序梁单元含剪切变形，
> `δ_shear/δ_bend = 9.6·EI/(k·G·A·L²) = 9.6×1.1124e9/(0.8333×7.923e10×0.18×36) = 2.50%`，
> 与实测偏差完全吻合——用欧拉梁公式对标时要把这一项算进容差，否则会误判为"网格太粗"。

### 基准 2：悬臂梁

```text
端部集中力 P：δ = P·L³/(3·E·I)；固定端 σ = P·L·(h/2)/I
一阶频率：f₁ = (1.8751)²/(2π) · √(E·I/(ρ·A·L⁴))
```

### 基准 3：反力平衡（静力通用）

```text
Σ约束反力（各方向） ≈ Σ外加荷载（各方向），差异 < 1%
自重工况：ΣRz 应 = ρ · V_网格 · g   ← ★ 用**网格体积**，不是理论几何体积
```

> 实测（`../examples/mixed/sphere_solid_selfweight.py`，实心球 R=1 m、C30、`basicSize=0.2`）：
> 网格体积 V=4.0851 m³ → ρVg = 2500×4.0851×9.81 = **100186.8 N**；
> `o62_ReactionForce.out` 实测 ΣRz = **100186.8 N**（比值 **1.0000**）、ΣRx=ΣRy=0.00 N。
> 这是最硬的判据：反力与自重完全平衡说明荷载、约束、求解链路都通——
> 若拿理论体积 4.1888 m³ 去比会差 2.5%（曲面离散），不要误判。

### 基准 4：模态 / 谱 sanity

```text
前 6 阶出现 ≈0 频率 ⇒ 存在刚体模态（约束不足）
总质量 ≈ 自重/g（+ 荷载转质量部分）；谱分析累计质量参与系数 ≥ 90%
```

> 模态/谱分析的质量源：自重（`density` + `Emload` 参与）+ 几何阶段的
> `LoadToMassSetting(loadToMassParas=[[工况id, 系数], ...])`；漏配会导致频率偏高、参与系数不足。

## 结果文件速查（`genfea-compute-*/Out<类型>/` 下 *.out）

| 文件 | 内容 | 备注 |
|---|---|---|
| `o11_NodeDisp.out` | 节点位移（MAG/UX/UY/UZ） | 默认输出 |
| `o41_ElemStress.out` / `o42_ElemMisesStress.out` | 单元应力分量 / Mises | 仅 out 文件（界面不展示） |

| 线单元内力 | 轴力/剪力/扭矩/弯矩 | 后处理"杆系内力"；轴力拉正压负 |

- **编码分工（实测 #56，2026-10-14 更正）**：`Out*/*.out`、`UserMeshParameter.txt` = **GBK**；`pserver.log` = **UTF-8**；
  `genfea-compute*/*.inp`、`pypcae/*.stru`、`task-log/*.txt`、`*.json` = **UTF-8**；
  一律带 `errors="ignore"`；用错编码会中文乱码、关键词计数恒 0（误判"算没算"）；
- **目录名可能带随机后缀**（实测 `genfea-compute-xnc5ol`）→ 用 `glob` + `mtime` 取最新，别硬编码；
- **多荷载步 `.out` 的结构**：`o11_NodeDisp.out` 每步一个 `(iStep, time)` 行 + 若干 `(iNum, ux, uy, uz)`；
  `o62_ReactionForce.out` 每步一个 `(iStep, time)` 行 + 若干 `(iFix, iNode, Rx, Ry, Rz[, Mx, My, Mz])`
  ——按"2 字段行"切步，别把所有步混在一起求和；
- **只读文本 `.out`**：禁止解析二进制（`*.dat`）、禁止到软件安装目录翻查内部文件；
- 节点结果为关联单元**平均值**，跨单元类型/板壳交叉处物理含义可能失真。
